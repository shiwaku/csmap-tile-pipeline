# csmap-py のパラメータ

CS立体図は **標高・傾斜・曲率** の3要素を合成したRGB画像。
各パラメータはこの合成の仕方を決める。

現行の全データセットで以下の設定を使用している。

```bash
--chunk_size 1024 \
--gf_size 12 --gf_sigma 3 \
--curvature_size 1 \
--height_scale 0 1000 \
--slope_scale 0 0.6 \
--curvature_scale -0.005 0.005 \
--max_workers 1
```

| パラメータ | 既定値 | 採用値 | 意味 |
|---|---|---|---|
| `--chunk_size` | 1024 | 1024 | 分割処理の単位（ピクセル）。小さくするとメモリ使用量が減る |
| `--max_workers` | 1 | 1 | 並列数。増やすとメモリ使用量が比例して増える |
| `--gf_size` | 12 | 12 | ガウシアンフィルタのサイズ。大きいほど滑らかになる |
| `--gf_sigma` | 3 | 3 | ガウシアンフィルタの標準偏差 |
| `--curvature_size` | 1 | 1 | 曲率フィルタのサイズ |
| `--height_scale` | 0 1000 | 0 1000 | 標高の表示レンジ(m)。対象地域の標高範囲に合わせる |
| `--slope_scale` | 0 1.5 | **0 0.6** | 傾斜の表示レンジ。既定より狭くして緩斜面のコントラストを上げている |
| `--curvature_scale` | -0.1 0.1 | **-0.005 0.005** | 曲率の表示レンジ。既定より大幅に狭くして微地形を強調している |

## 調整の指針

- **微地形が見えにくい** → `--curvature_scale` の幅を狭める（例 -0.003 0.003）
- **平野部が白飛びする** → `--slope_scale` の上限を上げる
- **高山地域を扱う** → `--height_scale` の上限を対象地域の最高標高に合わせる
- **メモリ不足で落ちる** → `--max_workers 1` にする。それでも落ちるなら `--chunk_size` を 512 や 256 に下げる

## 注意

パラメータを変えると**見た目が変わる**。既存の配信データと差し替える場合は、
同じパラメータを使わないと地図の印象が変わってしまう。

新規データセットで既存と揃えたい場合は、上記の採用値をそのまま使うこと。
