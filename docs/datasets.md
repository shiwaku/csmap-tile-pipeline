## 注意事項

- **pref-saitama**: 手元のソースは `saitama-csmap-v2`（2025-09-14）だが、サーバ側のタイルが
  v1 の可能性がある。配信中の `saitama-csmap-tiles` と、未展開のまま残っている
  `saitama-csmap-v2-tiles.zip`（20.4GB）の関係を確認すること。
- **pref-wakayama**: xs489works（216,085枚）と shiworks（213,859枚）の両方に存在する。
  収録範囲が異なる可能性があるため、統合前に照合が必要。
- **pref-hiroshima**: 2022年版（shiworks / 1,050,769枚）と旧版（xs489works / 335,398枚）が併存。
- **外部サイトからの参照がある**データセットは URL を変更できない。
  `pref-kyoto`（奈良文化財研究所ほか）、`pref-okayama`、`pref-nagano`、`pref-yamanashi`、`pref-toyama`。
  詳細は [webp.md](webp.md) の「URLを変えずに配信する」を参照。
