# NoData（透明領域）の扱い

**ラスタータイルで最も事故が起きやすいのがここ。**
NoData が正しく透明になっていないと、データの無い範囲（海、対象外の市町村、
LiDAR の欠測域）が不透明に塗り潰され、下のレイヤが見えなくなる。

---

## 実例: 東京都島しょ部の作り直し

2024-03 に生成したタイルは NoData が透明になっておらず、2025-05 に作り直した。

青ヶ島（shima-06）の CS立体図 GeoTIFF でアルファチャンネルを比較した結果:

| | アルファ平均 | 透明(0) | 不透明(255) |
|---|---|---|---|
| 旧 2024-03 | 254.4 | **0.0%** | 100.0% |
| 新 2025-05 | 177.7 | **29.7%** | 70.3% |

青ヶ島は小さな島で、タイル範囲の約30%が海にあたる。
旧版はその海域まで不透明に塗られていた。

バンド構成（RGBA 4バンド、Mask Flags: PER_DATASET ALPHA）は新旧とも同一で、
**見た目の構造だけでは判別できない。中身の統計を見ないと気づけない。**

---

## 検証方法

生成物のアルファチャンネルの分布を必ず確認する。

```bash
bash scripts/98-check-nodata.sh <GeoTIFFまたはタイルディレクトリ>
```

判断の目安:

| 透明の割合 | 判断 |
|---|---|
| 0% | ⚠ **NoDataが透明化されていない可能性が高い**（対象範囲が矩形いっぱいなら正常） |
| 数%〜数十% | 正常。海岸線や範囲境界が透明になっている |
| 100%近い | ⚠ データが入っていない可能性 |

対象範囲が矩形に完全に収まるデータ（内陸の市町村を矩形で切り出した場合など）では
0% が正しいこともある。**対象地域の形状と照らして判断すること。**

---

## 原因と対処

NoData が透明にならない原因は、多くの場合 **元DEMの NoData 設定**にある。

### 元DEMを確認する

```bash
gdalinfo <DEM.tif> | grep -E 'NoData|Mask Flags'
```

`NoData Value=` が出てこない場合、DEM に NoData が設定されていない。
csmap-py はその情報を使って透明領域を決めるため、上流で欠けていると下流まで伝わらない。

### DEM に NoData を設定する

```bash
# 既存ファイルのNoDataを宣言する（データは書き換えない）
gdal_edit.py -a_nodata -9999 <DEM.tif>

# VRT作成時に指定する
gdalbuildvrt -srcnodata -9999 -vrtnodata -9999 -input_file_list filelist.txt out.vrt
```

NoData値は配布元の仕様に合わせる（-9999、-32768、0 など）。
**0 を NoData にする場合は注意**。標高0mの海面と区別がつかなくなる。

### 投影変換で透明を保つ

```bash
gdalwarp -t_srs EPSG:3857 -dstalpha \
  -co BIGTIFF=YES -co COMPRESS=DEFLATE -co PREDICTOR=2 -co ZLEVEL=9 -co TILED=YES \
  <in.tif> <out-3857.tif>
```

`-dstalpha` を付けるとアルファバンドが生成される。
csmap-py の出力が既に RGBA の場合は不要（アルファがそのまま引き継がれる）。

---

## WebP でも透明は完全に保たれる

**WebP は非可逆モード（q=95）でも、アルファチャンネルは可逆で符号化される。**

同一の CS立体図から PNG と WebP のタイルを生成して比較した結果:

| 項目 | 結果 |
|---|---|
| 比較タイル数 | 12 |
| **アルファの最大差** | **0（完全一致）** |
| RGBの平均差（不透明部） | 2.08 / 255（0.8%） |
| 容量 | 528KB → 212KB |

透明率も PNG と完全に一致した（33.9% / 70.3% / 61.7%）。

**NoData の扱いに関して、WebP化によるリスクは無い。**
むしろ PNG から WebP に変換する場合も `cwebp` は既定でアルファを可逆保存するため、
既存タイルの透明領域はそのまま維持される。

## チェックリスト

タイルを本番に反映する前に確認する。

- [ ] 元DEM に NoData が設定されているか（`gdalinfo | grep NoData`）
- [ ] CS立体図 GeoTIFF が RGBA 4バンドになっているか
- [ ] アルファの透明率が対象地域の形状と整合するか（`98-check-nodata.sh`）
- [ ] 生成タイルが 4バンドを保っているか
- [ ] 実際に地図に載せて、海や範囲外が透けて見えるか

最後の目視確認は省略しない。統計上は正常でも、範囲の切り出しミスは目で見ないと気づけない。
